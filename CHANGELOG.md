# Изменения

## 4.0.3

**Свой значок на панели задач.** Окно Jarvis Code показывало на панели задач старый знак версии 2.0 (синий круг с «J»), а в меню значка — «Microsoft Edge»: окно открывается через Edge в режиме приложения, Windows считала его окном Edge, а значок брала из favicon, закэшированного для того же адреса `127.0.0.1:порт`. Теперь:

- favicon отдаётся по адресу с версией (`/favicon-4.0.3.ico`) и указан в `index.html` — закэшированный значок прошлых версий не подхватывается;
- окну задаётся свой AppUserModelID (`JarvisCode.App`) с именем «Jarvis Code», своим значком и командой запуска `JarvisCode.exe` — окно больше не группируется с Edge, в меню значка — «Jarvis Code», а «Закрепить на панели задач» закрепляет Jarvis Code, а не Edge;
- тот же AppUserModelID записывается в ярлыки Jarvis Code на рабочем столе и в «Пуске» (при установке и обновлении) — панель задач берёт имя и значок из ярлыка;
- старый кэш значка сбрасывается: один раз после обновления из профиля окна удаляются закэшированные favicon и значки веб-приложений (тема, акцент и вид панели сохраняются), кэш иконок Explorer обновляется.

У окна установщика — свой AppUserModelID, закрепить его нельзя.

## 4.0.0

**Только чат Notion.** Режим API убран целиком — вместе со входом по токену, аккаунтами, выбором агента, кредитами пространства и всем, что от них зависело. Вы пишете в окне Jarvis Code, отвечает агент в обычном чате Notion — через мост. Старые токены и аккаунты удаляются из `config.json` при первом запуске, имя пользователя сохраняется; старые чаты открываются как обычно.

**Чаты не привязаны к пространству.** История, память и контекст чата хранятся на ПК. Подключили мост в другом рабочем пространстве (или в новом чате Notion) — агент получает выжимку чата и последние сообщения и продолжает с того же места. Старые сообщения он перечитывает сам (`nc_history`), выжимку ведёт `nc_memory` (или поле `memory` в `nc_reply`).

**Перенос чата из Notion.** «Перенести чат» в панели: команда копируется в буфер — вставьте её в нужный чат Notion, и агент передаст всю переписку и выжимку в Jarvis Code (`nc_import`, длинные чаты — частями). Чат сразу открывается в окне, история — сворачиваемым блоком «История из Notion». Можно и из текста или файла `.md` / `.txt`.

**Своё хранилище.** Настройки → «Хранилище»: размер по разделам (чаты, контекст, вложения, снимки, копии файлов), свободное место и «Изменить папку…» — например, на большой диск. Данные переносятся на лету, без перезапуска; ссылки на вложения обновляются. «Открыть это хранилище» — подхватить уже существующее (после переустановки Windows или с другого ПК). Если диск отключён — временно используется папка данных, в окне предупреждение.

**Мышление.** Кнопка у поля ввода: «Быстро», «Обычно», «Глубоко», «Максимум» — для чата или по умолчанию для новых. Модель выбирается в самом чате Notion (Jarvis Code не может её переключать) — пункт меню открывает чат Notion.

**Мелочи.** «Повторить» на карточке ошибки; «/think», «/import», «/model» в командах; «Как к вам обращаться» и «Текст с картинок для агента» (OCR) в «Общих»; карточка «Подключите Jarvis Code к Notion AI» на главной, пока мост не подключён (один раз на каждое пространство).

## 3.1.0

**Пишите, пока агент работает.** Новое сообщение встаёт в очередь над полем ввода и уходит агенту вместе с результатами текущего шага — он учтёт уточнение, не дожидаясь конца ответа. «Отправить сейчас» прерывает шаг и передаёт сообщение сразу; сообщение можно убрать из очереди (текст вернётся в поле), а при «Стоп» неотправленное возвращается в поле ввода. Работает и через API, и в «Чате Notion».

**@-упоминания файлов.** «@» в поле ввода — нечёткий поиск по файлам и папкам проекта (стрелки, Enter или Tab), путь подставляется в сообщение.

**«Откатить все».** Под ответом агента — итог его правок: какие файлы изменены, сколько строк добавлено и удалено, и кнопка, которая одним нажатием возвращает все файлы ответа к состоянию до правок.

**Экран, буфер обмена, корзина.** Новые инструменты агента: `nc_screenshot` — снимок экрана (основной монитор или все; окно Jarvis Code на мгновение сворачивается), превью снимка прямо в ленте шагов и просмотр во весь экран; `nc_clipboard` — прочитать буфер обмена (текст, скопированные файлы, картинку) или положить в него текст; `nc_trash` — удаление в Корзину (можно восстановить) вместо безвозвратного `Remove-Item`. Экран и буфер — всегда с вопросом, в любом режиме («Всегда в этом чате» — для каждого инструмента отдельно), в автономном режиме запрещены. Корзина без вопроса — только внутри папки проекта в режимах «Полный доступ» и «Автономно»; корни дисков, системные и основные папки пользователя, сетевые и съёмные диски (там нет корзины) — отказ.

**Текст с картинок в режиме API.** Через Notion API агент не видит изображений — теперь для снимков экрана, картинок из буфера и `nc_view_image` он получает текст, распознанный встроенным OCR Windows (языки профиля, иначе английский).

**Свои «/»-команды.** Файлы `.md` в `.jarvis/commands` (или `.claude/commands`) проекта и в `~/.notion-code/commands` — это свои команды: `/deploy прод` отправит агенту текст `deploy.md`, а `$ARGUMENTS` в нём заменится на «прод». Описание в меню — из `description:` в начале файла или первая строка. `/commands` открывает личную папку команд (с примером).

**Сохранить в Markdown.** Меню чата → «Сохранить в Markdown»: сообщения, шаги агента и разрешения — файлом в «Загрузки», он сразу показывается в Проводнике.

**Исправления.** Русские буквы в выводе команд больше не превращаются в «�» на границе кусков вывода; лента остаётся внизу, пока загружаются картинки; склонения в итогах («3 объекта», «4 строки»); слишком большие картинки (снимок нескольких мониторов) для распознавания уменьшаются, а не пропускаются.

**Новый облик.** Спокойный интерфейс в духе Claude и ChatGPT: тёплая тёмная и светлая темы, пять акцентов, шрифты Inter, Source Serif 4 и JetBrains Mono (встроены — окно работает без интернета). Карточка разрешения с уровнем риска и клавишами Y/N, план задачи (`nc_todo`) над полем ввода, кнопка «Отменить правку» прямо на шаге, команды через «/» (`/init` — память проекта, `/review` — ревью изменений, `/plan`, `/ask`, `/auto`, `/full`, `/folder`, `/model`, `/new`), Shift+Tab — смена режима, Esc — остановка.

**Вложения без ограничений.** Ctrl+V работает в любом месте окна: скриншоты, файлы и папки из Проводника (по настоящему пути, без копирования), видео (с раскадровкой для агента), длинный текст — отдельной карточкой. Перетаскивание в любое место окна. Файлы до 4 ГБ загружаются потоково, с прогрессом и отменой. Превью картинок и видео, просмотр во весь экран.

**Быстрее и умнее.** Единый реестр инструментов для API и моста, пакетные вызовы `nc_batch`, мульти-правки `nc_multi_edit`, ответ-и-ожидание в пересылке через чат Notion (на один круг меньше), память проекта (`NOTION.md`, `JARVIS.md`, `AGENTS.md` или `CLAUDE.md`) и состояние git в контексте.

**Несколько пространств.** Переключение аккаунта сохраняет все чаты и их историю. Кончились кредиты — тот же чат продолжается в другом подключённом пространстве (история передаётся агенту), либо через чат Notion, либо останавливается — на выбор в настройках.

**Безопасность.** Каждая часть цепочки команд проверяется отдельно; распознаются скрытые команды (закодированный PowerShell, скачать-и-выполнить, отключение защитника, автозагрузка); зоны секретов (SSH, .env, браузеры, кошельки) — всегда с вопросом. Токены вырезаются из вывода команд. Токены Notion на диске шифруются Windows (DPAPI). Правки файлов — атомарные, с сохранением кодировки и переводов строк; копии до правок хранятся 14 дней. Ключ и адрес моста не менялись — подключение в Notion продолжает работать.

**Обновления и надёжность.** Автообновление из релизов GitHub или своего `latest.json`: фоновая загрузка, проверка SHA-256 (и подписи, если установленная версия подписана), установка по кнопке без потери настроек и моста. Отчёты о сбоях — локально и обезличенно, отправка только с согласия. Сборка поддерживает подпись Authenticode (`JC_SIGN_CERT` / `JC_SIGN_CMD`) и выпускает `latest.json` и `SHA256SUMS.txt`.
