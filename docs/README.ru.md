# Jarvis Code 4.2.0-beta.2

Упрощён центр управления: Обзор → Доступ → три понятных варианта.

Чтобы обычные команды не требовали постоянного подтверждения: остановите текущие задачи проекта, откройте «Центр управления → Доступ», выберите «Полный доступ к ПК», отметьте согласие и нажмите «Применить полный доступ». Режим текущего чата и права проекта согласуются одной кнопкой.

Секреты, системные запреты, пользовательские deny, согласие на экран/буфер, правила удаления и ограничения передачи данных сохраняются. Если глобально включено «только папка проекта», оно продолжает действовать. Права администратора Windows эта настройка не выдаёт.

Сборка неподписанная, предварительная. Windows может показать предупреждение SmartScreen. Установленную копию сборка не заменяет автоматически. Подробное описание и ограничения — ACCESS-NOTES.ru.md в исходниках.
