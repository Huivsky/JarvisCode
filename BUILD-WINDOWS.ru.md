- Windows-runner целиком прошёл: harness (13 групп), control-center (17 групп), session-integration (8 сценариев), smoke (сквозной HTTP/WS/MCP сценарий), context (9), security (156), files (18), commands (13), update (50), regression (9 групп).

- В скомпилированном EXE проверены создание чата, сохранение критерия, включение критерия в контекст и блокировка предпросмотра после запрета облачной передачи.
