# Фактическая проверка 4.2.0-beta.1

Выполнено в sandbox Linux / Node 24 через транспиляцию esbuild:
- test/harness.ts: 13 групп прошли; включены реальные Git init/commit/worktree, защита основной папки, ручные/командные/файловые критерии, ограниченный журнал, replay без действий и корректное завершение при ошибке подготовки контекста.
- test/session-integration.ts: 8 сценариев реальных JSON/MCP-вызовов и локального API. Проверены отдельные чаты, запрет смешанного scope, исключение файла, local-only, выключение истории/памяти, readonly, блокировка DONE без доказательств, безопасный replay и отказ до отправки контекста.
- regression: 9 групп; security: 156; files: 18; commands: 13; context: 9; control-center: 17 групп — прошли.
- Browser Chromium / Playwright: 12 проверок текущих компонентов с имитацией API, включая 5 новых сценариев харнесса; настольная и мобильная ширина 390 px без горизонтального переполнения. Скриншоты просмотрены.
- Полные графы frontend/backend компилируются esbuild. Это не нативная production-сборка Bun; для проверки графа используется временный ui-assets.gen.ts и external marked, временный файл исключён из ZIP.
- Статическая проверка трёх новых основных модулей harness.ts / transfer-gate.ts / worktrees.ts компилятором TypeScript 7.0.2 с Node typings: без ошибок. Это не полный typecheck проекта с закреплёнными зависимостями.

Дополнительно выполнено на Windows (Bun 1.4.4):
- Полная проверка типов проекта TypeScript 5.9.3 прошла.
- Все 10 наборов test/windows.ts прошли целиком, включая smoke, harness и session-integration.
- Собран release EXE. Проверен запуск именно готового файла в двух headless-режимах, UI-ресурсы, API критериев/контекста и запрет облачной передачи.

Не выполнено: установка/удаление, реестр/ярлыки, GUI/WebView, автоматический откат обновления и удалённый Notion E2E. Linux-специфичные desktop.ts и ngrok.ts явно исключены из Windows-runner; полный bun run test на Windows не объявляется прошедшим.

Предыдущая остановка передачи исходников устранена передачей обычных текстовых файлов вместо команды декодирования. Итоговые Windows-проверки прошли. См. BUILD-WINDOWS.ru.md для контрольной суммы EXE и полного отчёта.
